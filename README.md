# Ballerburgen Editor

**Create your own castles for the classic game Ballerburg!**

The Ballerburgen Editor allows you to create custom castles for [Ballerburg](https://www.eckhardkruse.net/atari_st/baller.html?en), the classic artillery game originally developed for the Atari ST.

Design your own fortresses, experiment with different layouts and share your creations with other Ballerburg players!

## Available Versions

The editor is available in two different implementations:

### Java Edition

A cross-platform version written in Java.

- Runs on systems supporting Java.
- Provides a graphical user interface for designing castles.
- Allows you to create and edit your own castle layouts.

[Go to the Java Edition](java/)

### Atari ST Edition

**Work in progress !!!**

A native version for the Atari ST, bringing castle editing to the original platform.

- Runs on Atari ST computers.
- Designed for the original hardware and environment.
- Create and edit castles directly on your Atari ST.

[Go to the Atari ST Edition](atari-st/)
