## Alert when the resource file is unavailable

`APP_ALERT_RESOURCES_LOAD_FAILED` deliberately has no `ALR_` ID, because this
alert must also be shown when the resource file cannot be loaded. The built-in
fallback texts are:

| Language | AES alert text |
|---|---|
| Deutsch | `[1][Die Anwendungsressourcen können nicht geladen werden.][Beenden]` |
| English | `[1][Unable to load application resources.][Quit]` |

The RSC text is used once the corresponding `ALR_` ID is present in the
generated `BALLERED.h`. Until then, or if the free string is missing, the
built-in English fallback is used.
